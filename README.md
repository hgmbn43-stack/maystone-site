# maystone.uk

The Maystone Sales Group website (November 2026 redesign). A short home page (dark hero with 3D logo stack and example leaderboard, your path, work-from-anywhere photos, example earnings slider, ambition paths, trust cards, founder quote) plus in-page views: How it works, Who we work with, For businesses, Questions (FAQ + privacy), Apply and Find reps. Photos in img/ are from Unsplash (free licence). The Apply and Find reps forms post to the Team Portal Apps Script (portal-script/Portal.gs), which saves them to the Applications and Enquiries tabs and emails harvey@maystone.uk.
